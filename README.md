# 🌌 Ephemeris

Ephemeris is a blazing-fast, local-first workspace and note-taking application. Built with modern web technologies, it provides a seamless, distraction-free environment for organizing your thoughts.

## Features
- **Local-First Architecture:** All of your notes, emojis, and cover images are stored locally in your browser using IndexedDB. No cloud sync means zero latency and complete privacy.
- **Rich Text Editing:** Powered by [Tiptap](https://tiptap.dev/), offering a robust block-based writing experience.
- **Minimalist Aesthetic:** Clean, premium design inspired by modern workspaces with smooth micro-animations.

## Tech Stack
- **Framework:** React + Vite
- **Database:** Dexie.js (IndexedDB wrapper)
- **State Management:** Zustand
- **Editor:** Tiptap
- **Styling:** Vanilla CSS Variables

## Getting Started

To run Ephemeris locally:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
